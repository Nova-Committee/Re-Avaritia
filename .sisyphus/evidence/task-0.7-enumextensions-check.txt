[4] ⚠️ Rarity 构造函数变更警告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
源模组使用的构造函数:
  (ILjava/lang/String;Lnet/minecraft/ChatFormatting;)V
  → 对应 Java: Rarity(int id, String name, ChatFormatting color)

NeoForge 26.1.2 中该构造函数仍然存在但标注 @Deprecated:
  "NeoForge: Use getStyleModifier()"

推荐的新构造函数:
  (ILjava/lang/String;Ljava/util/function/UnaryOperator;)V
  → 对应 Java: Rarity(int id, String name, UnaryOperator<Style> styleModifier)

迁移建议:
  - 简单移植: 直接沿用旧构造函数可正常工作（仅deprecated）
  - 最佳实践: 改为新构造函数 + UnaryOperator<Style> 参数
    例如: style -> style.withColor(ChatFormatting.GOLD).withItalic(true)
