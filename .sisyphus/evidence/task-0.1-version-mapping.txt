# Task 0.1 — NeoForge 26.1.2 version mapping verification

## Conclusion
NeoForge **26.1.2.65-beta** does **not** depend on Minecraft 1.21.1 or 1.21.11.
It targets **Minecraft 26.1.2**.

## Evidence

1. **NeoForge Maven metadata**
   - URL: https://maven.neoforged.net/releases/net/neoforged/neoforge/maven-metadata.xml
   - Evidence: `latest` and `release` are both `26.1.2.65-beta`, confirming this is the current 26.1.2-beta line.

2. **Specific POM for 26.1.2.65-beta**
   - URL: https://maven.neoforged.net/releases/net/neoforged/neoforge/26.1.2.65-beta/neoforge-26.1.2.65-beta.pom
   - Evidence: the published artifact is `26.1.2.65-beta`, and the SCM tag is `357d9afe962b901419e2ea3ffdd5c3a5044f6b21`.
   - The POM itself does not encode a legacy 1.21.x dependency; it points to the 26.1.2 release line.

3. **ModDev config for 26.1.2.65-beta**
   - URL: https://maven.neoforged.net/releases/net/neoforged/neoforge/26.1.2.65-beta/neoforge-26.1.2.65-beta-moddev-config.json
   - Evidence: the `runs.client` entry passes `--version 26.1.2.65-beta`, and the config is built against `neoform:26.1.2-1`.
   - This confirms the toolchain for this NeoForge build is aligned to the 26.1.2 Minecraft line.

4. **NeoForge 26.1 release notes**
   - URL: https://neoforged.net/news/26.1release/
   - Evidence: the release notes explain the new versioning model: the **first three components identify the Minecraft version**. Example: `26.1.0.10-beta` means Minecraft `26.1.0` and NeoForge release `10`.
   - Therefore, `26.1.2.65-beta` means Minecraft `26.1.2` and NeoForge release `65-beta`.
   - The same page also says 26.1 is the next stable modding version replacing 1.21.1, which is a **migration context**, not the version dependency for the 26.1.2 artifact.

5. **NeoForge 26.1.x branch gradle.properties**
   - URL: https://raw.githubusercontent.com/neoforged/NeoForge/26.1.x/gradle.properties
   - Evidence: `minecraft_version=26.1.2`
   - Evidence: `neoforge_snapshot_next_stable=26.1.2`
   - This is the clearest direct source: the 26.1.x branch is configured for Minecraft **26.1.2**.

## Answer to the challenge
- **It is not Minecraft 1.21.11.**
- **It is not Minecraft 1.21.1.**
- **It is Minecraft 26.1.2.**

## Notes
- The earlier primer title caused a version-number interpretation error.
- The “1.21.11” mention in the release notes is part of the migration story from the old line, not the dependency target of NeoForge 26.1.2.65-beta.
